# 🧩 Puzzles

A collection of fun and challenging web-based puzzles.

## 🚀 How to Play
1. Open the project in your web browser.
2. Try to complete all levels!

## 🛠 Technologies Used
* HTML5
* CSS3
* JavaScript

## 📂 Project Structure
* `index.html` - The main entry point.
* `style.css` - Styling and layout.
* `main.js` - Logic and puzzle mechanics.
